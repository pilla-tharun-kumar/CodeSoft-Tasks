# CodSoft Python programming tasks

Five standalone command-line Python applications. Python 3.8+ is required; no third-party packages are needed. Run each with `python <folder>/main.py` from the repository root.

| Folder | Task |
| --- | --- |
| `01_todo` | Add, view, edit, complete, and delete tasks; saves to a local JSON file. |
| `02_calculator` | Add, subtract, multiply, and divide two numbers. |
| `03_password_generator` | Generate a password with chosen length and complexity using cryptographic randomness. |
| `04_rock_paper_scissors` | Play repeated rounds against the computer with score tracking. |
| `05_contact_book` | Save, list, search, update, and delete contacts in a local JSON file. |

The JSON data files are created on first use and ignored by Git.
